# Julio’s Jewelry Repair — template-based deployment

This site is rebuilt directly from the Ultimate Gun Shop template structure and styling, preserving its typography, dark background, navigation, CTA buttons, responsive layout rhythm, and compact mobile-first feel while replacing the business content and imagery with Julio’s Jewelry Repair.

## Deploy
- Upload this folder (or ZIP contents) to your static host with `index.html` at the publish root.
- No build command is required.
- Publish directory: `.`
- The domain is not changed by this package.
