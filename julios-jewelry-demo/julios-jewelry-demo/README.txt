JULIO'S JEWELRY REPAIR — DEMO WEBSITE

Open index.html in a browser to preview locally.

Netlify deployment:
1. Go to Netlify and choose Add new site > Deploy manually.
2. Drag the julios-jewelry-demo folder contents (index.html and assets folder) or upload the ZIP.
3. Netlify will publish the static demo. No build command is needed.

Included:
- Responsive desktop and mobile design
- Supplied logo and jewelry images stored locally (no remote image/CDN dependencies)
- Click-to-call and Google Maps directions
- Custom nameplate showcase
- Demo inquiry form that prepares a text message; it does not store or submit customer data to a backend

Before using as the real business website:
- Confirm services, materials, pricing, hours, and product availability with the owner.
- Connect a real form/CRM if inquiries should be submitted online.
- Confirm the logo and all photos are approved for public use.
- Replace demo preview wording if desired after owner approval.
