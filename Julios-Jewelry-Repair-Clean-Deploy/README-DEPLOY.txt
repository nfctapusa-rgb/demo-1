JULIO'S JEWELRY REPAIR — CLEAN DEPLOY PACKAGE

Contents:
- index.html
- jjr/ contains only the supplied Julio's jewelry business images and review/platform icons.

Deploy:
1. Upload the contents of this folder to the root of the GitHub repository (not the enclosing folder).
2. Keep index.html at repository root and the jjr folder beside it.
3. In Vercel, deploy the connected repository. No build command is required for this static HTML site.
4. Confirm all /jjr/ image requests return successfully.

Important:
- Google and Yelp buttons are search links, not verified direct business profile URLs.
- Confirm the shop's phone number, address, current hours, and review permissions before publishing.
